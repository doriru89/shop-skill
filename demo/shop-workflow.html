Shop Skill Walkthrough

One purchase request, four steps, a human decision between every pair. Finds your best product, not the best product.

How to read this demo. This page replays one synthetic run (outdoor Christmas lights for a two-storey house in a cold climate) exactly as the user would see it, step by step. Click a decision to move on, use the arrow keys to jump between steps, and watch the gate panel count the evidence before each decision is offered.

    Evidence and decision never share a turn: Turn A renders the evidence in the message body and ends with no tool call; Turn B asks only the decision, because tool output is collapsed in most Claude Code surfaces. ← → move between steps.

    All brands are real; prices, counts and quotes are illustrative placeholders from a synthetic run.
